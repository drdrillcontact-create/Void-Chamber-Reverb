# Motion Lab

Run from the repository root:

```sh
python3 -m http.server 8081 --bind 0.0.0.0 --directory tools/motion-preview
```

Ten distinct Canvas animation studies over the approved static scene. Demo signal is silent and deterministic; upload a local audio file for Web Audio frequency-band response. Uploaded audio stays in the browser. Audio-output reverb energy is not available here: the visual tail is simulated. No plugin DSP or editor code is modified by this lab.

Select each numbered mode, trigger a transient, tune intensity/speed, pause, or enable eight-second automatic comparison. Final JUCE rendering performance and exact appearance require separate implementation and verification after selection.
